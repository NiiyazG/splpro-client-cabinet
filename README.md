# SPLPRO — прототип личного кабинета конечного клиента

Интерактивный прототип кабинета для трёх архетипов корпоративного клиента SPLPRO:

- заказчик-девелопер;
- подрядчик;
- проектировщик.

## Что реализовано

- персонализируемый дашборд с KPI и целевыми действиями;
- портфель объектов и инженерных разделов;
- расчёты и переход к конфигураторам SPLPRO;
- заказы с индикатором синхронизации 1С;
- чек-листы «что требуется с вашей стороны»;
- представление стадий производства и журнала событий;
- поставки, документы, сервис и управленческая аналитика;
- адаптивная версия для мобильных устройств.

> Это UX-прототип. Цифры и события в интерфейсе — демонстрационные данные, а не сведения из продуктивной 1С или производственной системы.

## Запуск

Без сборки — откройте `index.html` или запустите локальный сервер:

```bash
python -m http.server 4173
```

После запуска откройте `http://localhost:4173`.

## Дизайн

Прототип следует направлению SPLPRO: Open Sans, светлый фон, монохромная палитра, плоские поверхности, тонкие границы, компактная плотность данных и чёрные основные действия. Использованы референсы [splpro.ru](https://splpro.ru/), [подбор оборудования](https://splpro.ru/selections/) и переданный Figma-макет.
