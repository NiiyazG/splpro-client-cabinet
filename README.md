# SPLPRO — прототип личного кабинета конечного клиента

Интерактивный прототип кабинета для трёх архетипов корпоративного клиента SPLPRO:

- заказчик-девелопер;
- подрядчик;
- проектировщик.

## Что реализовано

- персонализируемый дашборд с KPI и CTA для трёх архетипов;
- стадии дорожной карты 3.2-2: `Предпроект → Проект → Ноль → Каркас → Горящий → Закончен`;
- создание объектов, поиск и фильтрация портфеля;
- переход во внешние конфигураторы SPLPRO и AQUASTRONG;
- единая история «Мои подборы» текущего пользователя;
- привязка непривязанного подбора к объекту из портфеля с сохранением после перезагрузки;
- рабочие заявки менеджера: объект, товарная группа, исходные данные, ответственный, SLA/дедлайн и версии дополнений;
- импорт номера/ссылки результата подбора и привязка к объекту;
- согласование конкретной версии результата или возврат на доработку;
- создание из результата черновика заказа для последующей передачи в 1С;
- заказы с индикатором демонстрационной сверки 1С, оплатой, задолженностью, обеспечением и запросом резерва;
- сохраняемые чек-листы «что требуется с вашей стороны»;
- запрос поставки, контакт принимающего и адрес разгрузки;
- загрузка метаданных документов и скачивание карточки;
- создание сервисных обращений;
- целевое представление стадий производства и журнала событий;
- аналитика по текущему состоянию и экспорт CSV;
- сохранение состояния в `localStorage` и адаптивная мобильная версия.

Подбор оборудования **не реализуется внутри кабинета**. Кабинет открывает конфигуратор сайта, получает историю результатов текущего пользователя и позволяет связать выбранный результат с объектом. Ручное добавление номера оставлено резервным сценарием прототипа. Неактивные конфигураторы отмечены как готовящиеся и не имитируют работающий расчёт.

> Это функциональный UX-прототип. Созданные пользователем записи сохраняются локально в браузере. Цифры, сверка 1С и производственные события — демонстрационные данные, а не сведения из продуктивных систем.

## Запуск

Без сборки — откройте `index.html` или запустите локальный сервер:

```bash
python -m http.server 4173
```

После запуска откройте `http://localhost:4173`.

## Проверка

```bash
npm install
npm test
```

Smoke-тест самостоятельно запускает локальный сервер и системный Chrome, проходит создание объекта, заявку на подбор и её новую версию, внешний импорт результата, черновик заказа, запрос резерва, сохранение чек-листа, поставку, документ, обращение, дорожную карту, CSV-экспорт, security-регрессии и мобильную проверку переполнения.

## Дизайн

Прототип следует направлению SPLPRO: Open Sans, светлый фон, монохромная палитра, плоские поверхности, тонкие границы, компактная плотность данных и чёрные основные действия. Использованы референсы [splpro.ru](https://splpro.ru/), [подбор оборудования](https://splpro.ru/selections/) и переданный Figma-макет.
